# Security policy

## Reporting a vulnerability

Please report security vulnerabilities to Will at [will@wtadler.com](mailto:will@wtadler.com) rather than opening a public issue.

Please include a description of the vulnerability, steps to reproduce, its potential impact, and any suggested fix.

## More

The [Security page](https://floorvote.org/docs/security/) describes what FloorVote protects for you and what a self-hosting operator stays responsible for.
